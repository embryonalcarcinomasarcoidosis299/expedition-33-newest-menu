## 🎯 What This App Does

expedition-33-newest-menu is a runtime boss music swapper. In plain terms: while Clair Obscur: Expedition 33 is running, this tool listens for boss encounters and swaps the music that plays for them, using a lightweight overlay you can open at any time with a hotkey.

## 🛠️ Troubleshooting

**The overlay does not appear.**
Make sure the game window is the active window when you press the hotkey. Try pressing it again after clicking once inside the game. If it still does not show, close both the game and the tool, then start the tool first and the game second.

**Music does not change during a fight.**
Confirm that the encounter you selected is the one currently playing. Some encounters share music tracks; changing one may not change another. Also check that the file you selected is a supported audio format.

**The application closes immediately.**
Move the file out of your Downloads folder into a normal folder such as `C:\Games\Expedition33Music` and try again. A blocked or read-only folder is the most common cause.

**Windows shows a security prompt.**
Click **More info**, then **Run anyway**. This prompt appears for many independent tools that are not signed with a commercial certificate.

**The game updates and music stops swapping.**
Download the newest release from the link above. Updates to the game are frequently followed by updated releases of this tool.
